# Figure source data

CSV files here are either direct copies of checked-in project result tables or small derived summaries from the local FIRMS/POWER cache. The complete raw datasets are not repackaged. `recreate_figures.py` regenerates all PNG and PDF figure exports using only these files. Source paths, SHA-256 digests, and derived-file descriptions are in `source_manifest.json`. The motor-monitor source has a non-commercial license; only aggregate evaluation summaries are included. Disease image files are not redistributed.
